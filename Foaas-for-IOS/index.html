Building an iOS App with FOAAS

Swift와 Alamofire를 활용해 오픈 API를 작은 Apple-platform 앱으로 연결해 본 프로젝트 기록입니다.

April 25, 2022·SwiftAlamofireiOS

개요

Github의 awesome-apis 저장소를 둘러보던 중 FOAAS(Fuck Off As A Service)라는 오픈 API를 발견했습니다. iOS 공부를 겸해 인증과 SSL이 필요하지 않은 API를 실험 대상으로 삼아 간단한 앱을 만들어 보기로 했습니다.

이 프로젝트는 API를 실제 사용자 경험으로 바꾸는 과정에서 네트워크 요청, macOS 메뉴바 앱, SwiftUI 라이프사이클을 함께 탐색한 기록입니다.

진행하며 마주한 문제

  • 현재 재생 중인 음악 정보를 어떻게 가져올 것인가
  • macOS 메뉴바 앱을 어떻게 구성할 것인가
  • Alamofire를 사용해 네트워크 요청을 어떻게 구성할 것인가
  • NSPopover의 anchor arrow를 어떻게 다루고 Human Interface Guidelines를 어떻게 지킬 것인가

Alamofire와 API 연결

Alamofire 공식 문서를 참고해 API 요청을 구성하고, 응답을 앱 화면에서 사용할 수 있는 형태로 변환했습니다. 작은 프로젝트였지만 외부 API의 경계와 실패 가능성을 직접 확인하는 좋은 실험이었습니다.

메뉴바와 팝오버

NSPopover 기반 메뉴바 앱 예제를 살펴보며 AppDelegate와 애플리케이션 라이프사이클을 SwiftUI 앱에 연결하는 방법을 학습했습니다. UI 동작을 구현하는 것뿐 아니라 macOS의 기본 상호작용을 존중하는 것도 중요한 과제였습니다.

마치며

강의를 따라가며 배우는 것도 중요하지만, 직접 작은 제품을 구상하고 구현하면서 문제를 만나는 과정 역시 큰 학습이 됩니다. 이 프로젝트는 SwiftUI, 네트워크 통신, macOS 앱 생명주기를 함께 연습할 수 있었던 출발점이었습니다.
